PETUNJUK SINGKAT
Dari data buku ke cover AI
  1. 1
    Isi informasi buku
    Masukkan judul, penulis, halaman, jenjang, kelas, dan daftar isi.
  2. 2
    Pilih hero, warna, dan style
    Tentukan hero, strategi warna, genre font, text effect, style badge kelas, dan nuansa tema.
  3. 3
    Tambahkan detail pendukung
    Isi teks bawah penulis, teks bawah kelas, catatan hero, dan instruksi custom bila diperlukan.
  4. 4
    Generate JSON
    Spine, ukuran kanvas, layout lock, sinopsis, dan negative prompt disusun otomatis.
  5. 5
    Buka ChatGPT
    Klik ChatGPT atau Gemini. JSON otomatis disalin sebelum tab AI dibuka. Logo diunggah langsung pada chat AI.
Tidak ada database.
Aplikasi hanya memproses form secara stateless untuk menyusun prompt.
